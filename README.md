# Orvane Assets (template de démonstration)
Template React + Vite de gestion d'actifs précieux. **Toutes les données sont fictives.**
```
npm install
npm run dev
```
Connexion démo : `demo@orvane.test` / `demo1234`. Les modifications sont stockées dans le localStorage (bouton « Réinitialiser » dans Profil).
Structure : `src/pages` (pages), `src/components` (UI, mise en page, inventaire), `src/data/demo.js` (données), `src/store.jsx` (état), `src/styles.css`.
